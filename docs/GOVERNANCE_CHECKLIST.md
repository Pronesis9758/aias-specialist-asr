# AI Governance 제출 체크리스트

## 데이터 승인

- [ ] 데이터 소유자와 승인자를 확인했다.
- [ ] 수집 목적, 사용 범위, 보관 기한과 삭제 담당자를 기록했다.
- [ ] 작업자·고객 개인정보 및 영업비밀 포함 여부를 검토했다.
- [ ] 비식별화 결과를 사람이 확인했다.
- [ ] Colab 등 외부 처리 환경 사용 승인을 받았다.
- [ ] 각 manifest 행의 `approval_id`가 승인 문서와 일치한다.
- [ ] 정답 전사를 별도 검수자가 확인했다.

`governance.mode=strict_private` 설정에서는 승인 문서, 비식별 표시, 전사 검수와
화자 독립 split이 누락되면 파이프라인이 실행되지 않는다.

## 데이터 흐름과 보안

1. 원본 음성은 Git에 커밋하지 않는다.
2. 승인된 사내 저장소 또는 승인된 비공개 Drive 경로에 저장한다.
3. 실행 산출물에도 정답·예측 문장이 포함될 수 있으므로 원본과 동일한 접근 정책을 적용한다.
4. 보관 기한 종료 시 음성, manifest, checkpoint, 예측, 보고서와 백업을 함께 삭제한다.
5. 토큰·비밀번호·서비스 계정 키를 config, 노트북, 보고서에 저장하지 않는다.

## 모델 및 출력 안전

- [ ] ASR 결과를 설비 제어 명령으로 자동 실행하지 않는다.
- [ ] 안전·품질 판단에 사용되는 전사는 사람이 확인한다.
- [ ] 누락·환각·숫자·설비번호 오류 사례를 별도로 분석한다.
- [ ] 화자, 성별·연령대(수집이 승인된 경우), 소음, 마이크, 발화 길이별 성능을 점검한다.
- [ ] 최종 보고서에 데이터 규모, 대표성, 단일 seed와 알려진 한계를 표시한다.

## 라이선스

- [ ] 데이터셋 저작자, 원본 링크, 라이선스 링크와 변경 여부를 표시한다.
- [ ] 모델 가중치와 코드 라이선스를 확인한다.
- [ ] `THIRD_PARTY_NOTICES.md`와 실제 설치 환경의 패키지 목록을 함께 제출한다.
- [ ] 프로젝트 자체 배포 라이선스는 소유자·회사 정책에 따라 별도로 결정한다.

본 체크리스트는 기술적 통제와 증빙을 위한 것이며 법률 자문을 대신하지 않는다.
